# Security Policy

Please do not report plaintext secrets found in third-party systems to this repository's issues without redaction.

For protocol data:

- Never commit real passwords, API keys, or private keys into examples or tests.
- See [docs/security-and-redaction.md](docs/security-and-redaction.md).

To report a vulnerability in tooling that consumes this spec, open a private security advisory on GitHub when available, or email the maintainer listed in the GitHub profile.
